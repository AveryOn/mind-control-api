## Testing Platform — Backend

### Description
Backend application for an educational testing platform.
Handles business logic for test creation, assignment, submission, review, and role-based access.

### Scope
- Role-based access control (teacher, student)
- Test and question management
- Test assignment and submission flows
- Manual and automatic test evaluation
- Review and approval workflow
- Notifications and status tracking
- Modular application architecture

### Tech
- Node.js
- TypeScript
- AdonisJS
- PostgreSQL
- Adonis Lucid ORM
- Adonis Auth
- VineJS (validation)

### Notes
- Part of a fullstack project
- Backend only
- Modular architecture
- Focus on business logic and data integrity
